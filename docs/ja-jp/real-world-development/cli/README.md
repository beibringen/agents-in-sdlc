**[GitHub Copilot CLI][about-copilot-cli]** は、ターミナルで GitHub Copilot をエージェント型コーディングアシスタントとして利用できます。コードベースを調査し、コードを生成し、コマンドを実行し、外部ツールに接続できます。すべてコマンドラインで行えるため、グラフィカルエディターに切り替えずに作業を続けられます。

このワークショップでは、Tailspin Toys の一連のワークフローに取り組みます。

1. Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、プロジェクトの使い方を確認します。
2. 星評価の小さな変更を行い、ブラウザーで確認して、最初の pull request (PR) を手動でマージします。
3. フィルター機能の Issue から開始し、Plan モードで実装方法を決め、Autopilot モードで構築して、Interactive モードでレビューします。
4. リポジトリの指示を更新し、フィルター機能の作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズし、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーでフィルター機能を確認します。
7. QA カスタムエージェントを作成して使い、要件、カバレッジ、検証の根拠をレビューします。
8. フィルター機能の変更全体をレビューし、PR に Agent Merge を使用します。
9. コンテキスト、モデル、共有、省略可能な cloud agent への委任に使う便利なスラッシュコマンドを確認します。

ワークショップの焦点を絞るため、PR は2つ作成します。1つ目は星評価、2つ目は指示の更新、スキルの更新、QA プロファイル、テストを含むフィルター機能です。フィルター機能と品質ワークフローは、1つの会話とブランチを共有するため、ツールを確認しながら作業を活用できます。

## 前提条件

このワークショップに参加する前に、次のものを用意してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** のいずれかのプランが設定された GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンドライン操作の基本的な知識

> [!TIP]
> 有料プランを利用していない場合、認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使用するエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用している場合は、管理者が Copilot CLI を有効にしていることを確認してください。
